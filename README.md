# Дневник

Независимый школьный планировщик: Kotlin Multiplatform, Android Jetpack Compose
Material 3 и нативный SwiftUI-клиент. https://github.com/Timofeyk42/dnevnik
Проект не является официальным приложением МЭШ или mos.ru.

## Android 0.3.0

- Расписание с одной или двумя неделями; неделя выбирается вручную.
- Импорт JSON v1/v2, проверка, предпросмотр, подтверждение замены и экспорт.
- Создание расписания, редактор уроков, времени, кабинетов, учителей и колонок.
- Пустые варианты, повторяющиеся предметы и ЗС сохраняются.
- Календарь контрольных, занятий и событий; задания с отметкой выполнения.
- Передача события в системный редактор календаря, в том числе Google.
  Пользователь выбирает календарь и подтверждает; это не автоматическая синхронизация.
- Системная/светлая/тёмная тема, динамические цвета, компактность, скрытие учителей.
- Атомарное хранение; резервная копия календаря и настроек с восстановлением.

**МЭШ API и OAuth не реализованы и не подключены.** Подготовлены отключённые
шаблоны и [инструкция интеграции](docs/INTEGRATION_HANDOFF.md). Нет выдуманных
endpoints или клиентских идентификаторов. Оценки не редактируются. Вход на сайте
в браузере не авторизует приложение.

Сохранение личных переносов при обновлении будущего источника реализовано в общем
ядре и тестах. Живых данных МЭШ, локального ИИ, фоновых уведомлений,
Google API sync и серверной части нет; эти функции нельзя считать выполненными.

## Сборка

JDK 17, Android SDK 36; версии закреплены. SDK 37 может стоять рядом,
но compile/target SDK сейчас 36. Указать SDK в игнорируемом local.properties
или ANDROID_HOME.

```sh
./gradlew :shared:jvmTest :androidApp:testDebugUnitTest :androidApp:lintDebug :androidApp:assembleDebug
```

APK: androidApp/build/outputs/apk/debug/androidApp-debug.apk.
Debug устанавливается как отдельное приложение «Дневник (тест)» с applicationId
org.opendnevnik.android.debug. Это позволяет сохранить исходную установленную версию.
На Windows — gradlew.bat и ASCII-путь checkout/build. Junction может разрешаться
Android Gradle обратно в исходный кириллический путь. APK не устанавливается
автоматически. Release signing и публикация в магазинах не настроены.

## iOS

[SwiftUI-клиент](iosApp/README.md): расписание, редактор уроков, импорт с
предпросмотром, календарь, задания и тема. Валидация — общее Kotlin-ядро.
Используются нативные компоненты, оформление зависит от iOS/SDK.
На Windows iOS не собирается; добавлен macOS CI. ИИ для iOS не планируется.
Статус и ограничения: [IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md).

Проверки Pixel и независимое ревью: [REVIEW.md](docs/REVIEW.md).
Устройственные тесты запускаются командой `./gradlew :androidApp:connectedDebugAndroidTest`
на подключённом телефоне с разрешённой USB-отладкой. Используйте отдельную `.debug`
установку с синтетическими данными: тест импорта заменяет её расписание и добавляет события.

## Приватность

В Android нет INTERNET permission, рекламы, аналитики или автоматической отправки
учебных данных. Хранилище приватное, системный backup отключён. Экспортированные
файлы и события доступны выбранному пользователем хранилищу/календарю.
Календарь может синхронизировать их через своего провайдера; повторный экспорт
может создать дубликат.

В репозитории только синтетические примеры. Реальные школьные сведения, фото,
секреты, ключи подписи, настройки машины и кеши не публикуются.
