# Подключение МЭШ после согласования

API и OAuth намеренно не реализованы. Не добавлять endpoints, DTO или поля токенов
на основании предположений. Существующие `mesh/api`, `mesh/oauth`, `mesh/data`,
Android `auth` остаются небольшими отключёнными шаблонами.

1. Получить регистрацию собственного public mobile client, точный протокол,
   redirect URI, scopes, тестовую среду и договорённость о разрешённых данных.
2. Реализовать транспорт и DTO в `mesh/api`, OAuth в `mesh/oauth` и платформенные
   хранилища. Системный браузер; PKCE/state и правила redirect по контракту провайдера.
3. В `MeshDiaryMapper` проверить принадлежность аккаунту/ученику и перевести ответ
   в доменные данные. Оценки доступны только для чтения.
4. Календарные контрольные преобразовать в `PlannerEvent` с `EventSource`.
   `source.key` должен включать непрозрачный локальный namespace аккаунта/профиля
   и стабильный ключ источника. Название/номер урока не являются идентификатором.
5. `PlannerRules.reconcile` вызывается только после **полного успешного снимка**
   контрольных данного namespace. Ошибка сети, неполная страница и 401 не означают
   пустой снимок. Функция сохраняет личные даты/заметки, обновляет исходные даты,
   помечает исчезнувшие события для ручного разбора. Повтор снимка не дублирует записи.
6. Датированное расписание МЭШ реализовать отдельной моделью; не преобразовывать
   его в циклический шаблон v1/v2. Личный локальный шаблон продолжает работать отдельно.
7. Подключать репозиторий к ViewModel только после контрактных тестов. Состояния
   «не подключено», «нет данных», «offline со снимком», «сессия истекла» различаются.
8. На logout отменять запросы, очищать токены/кеш текущего профиля. Личные события
   и экспортированные пользователем копии нельзя молча удалять.

## Обязательные проверки интеграции

- Просроченная сессия, неверный/replayed callback, refresh в гонке, logout во время запроса.
- Чужой профиль, смена аккаунта, удаление/перенос контрольной, пагинация и частичный ответ.
- 401/403/429/5xx, тайм-аут, malformed JSON, несовместимая версия DTO.
- Токены отсутствуют в UI state, логах, backup, clipboard и экспортируемых файлах.
- Синтетические fixtures и отсутствие скрытого password/cookie interception.

## Необходимые решения вне кода

Google API sync требует отдельного собственного OAuth-клиента и настройки scopes;
текущая Android-интеграция — пользовательский ACTION_INSERT, без чтения календарей.
AI/NPU остаётся отдельным исследованием подходящего для школьного продукта движка;
ML Kit GenAI не включён, пользовательская плашка 18+ не снимает условия Google.
