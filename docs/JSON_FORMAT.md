# Формат расписания

## v2: чередующиеся недели и параллельные столбцы

Копируемая инструкция теперь использует v2. `weeks` содержит одну или две недели с номерами `1` и `2`, каждая со своим `days`. Неделя выбирается пользователем вручную: без даты начала цикла приложение не определяет её автоматически.

```json
{
  "schemaVersion": 2,
  "name": "Моё расписание",
  "timeZone": "Europe/Moscow",
  "weeks": [
    {"number": 1, "days": [{"day": "monday", "lessons": [
      {"number": 1, "subject": "Математика", "room": "100"},
      {"number": 2, "variants": [{"subject": "Физика ЗС", "room": "101"}, null]}
    ]}]},
    {"number": 2, "days": [{"day": "monday", "lessons": [
      {"number": 1, "subject": "Литература", "room": "102"}
    ]}]}
  ]
}
```

День и номер урока могут повторяться в разных неделях, но внутри одной недели остаются уникальными. В корне v2 нет `days`: он находится внутри недель. Номера недель уникальны; для двух недель нужны 1 и 2. У каждой недели от 1 до 7 дней.

Обычный урок содержит `subject`, необязательные `room` и `teacher`. При параллельных столбцах используется `variants` из 2–4 элементов слева направо; каждый вариант содержит предмет и необязательные кабинет/учителя. `null` обозначает пустую колонку. Хотя бы один вариант должен быть заполнен. При `variants` предмет/кабинет/учитель не задаются одновременно на уровне урока. Время относится к номеру урока, а не отдельной колонке.

Ячейка на 3–4 урока преобразуется в два урока с номерами 3 и 4. Ячейка на всю ширину дня — общий предмет; половина дня с пустой соседней колонкой — варианты с `null`, а не общий предмет. Названия с ЗС сохраняются целиком. Время, которого нет на фото, не добавляется. Подписи «левая/правая колонка» не означают, что приложение знает подгруппу ученика.

Машиночитаемая схема: `schema/schedule-v2.schema.json`. Временные пересечения, уникальность дней/номеров и номера недель дополнительно проверяет `ScheduleJson`.

## v1: совместимость с первой версией

JSON v1 — один недельный шаблон. Ранее сохранённые и экспортированные файлы продолжают читаться. Он не содержит оценок, ДЗ и контрольных. Часовой пояс — `Europe/Moscow`. Особые даты, каникулы и изменения уроков пока не поддерживаются.

```json
{
  "schemaVersion": 1,
  "name": "Моё расписание",
  "timeZone": "Europe/Moscow",
  "days": [
    {
      "day": "monday",
      "lessons": [
        { "number": 0, "subject": "ЗС", "startTime": null, "endTime": null, "room": null, "teacher": null },
        { "number": 1, "subject": "Математика", "startTime": "08:30", "endTime": "09:15", "room": "204", "teacher": null }
      ]
    }
  ]
}
```

Это пример формата; номера и время реального расписания берутся только с фото.

| Поле | Ограничение |
| --- | --- |
| `schemaVersion` | Обязательное целое число `1` |
| `name` | Обязательная непустая строка, до 80 символов |
| `timeZone` | Обязательная строка `Europe/Moscow` |
| `days` | От 1 до 7 дней, дни не повторяются |
| `day` | `monday`, `tuesday`, `wednesday`, `thursday`, `friday`, `saturday`, `sunday` |
| `lessons` | Обязательный массив, от 0 до 20 уроков |
| `number` | Обязательное целое 0–20, уникальное внутри дня |
| `subject` | Обязательная непустая строка, до 100 символов |
| `startTime`, `endTime` | `HH:mm`, оба указаны или оба `null`/отсутствуют |
| `room` | `null`/отсутствует либо непустая строка до 40 символов |
| `teacher` | `null`/отсутствует либо непустая строка до 120 символов |

Начало раньше окончания; по возрастанию номера уроки не пересекаются и не идут назад во времени. Дни и уроки сортируются после проверки. Отсутствие времени даёт предупреждение, но допускает импорт. Пропущенный день отличается от явно пустого `lessons: []`.

ЗС сохраняется в `subject` как обычный урок без специальной категории. Сдвоенные предметы задаются двумя уроками с разными номерами.

Импорт допускает UTF-8 BOM и внешние пробелы. Лимит — 262144 байта фактического содержимого, вложенность — до 12. Неизвестные поля, повторяющиеся ключи (включая Unicode escapes), комментарии, Markdown, управляющие символы и управляющие направлением текста символы в названиях отклоняются. Название файла и MIME не заменяют проверку содержимого.

JSON Schema описывает структуру; временные пересечения и уникальность номера/дня дополнительно проверяет `ScheduleJson`. Каноничная инструкция для ИИ находится в `PhotoPrompt.kt` и копируется из интерфейса. Её пример проверяется тестом настоящего парсера.
