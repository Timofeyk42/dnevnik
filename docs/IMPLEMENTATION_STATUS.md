# Состояние реализации

24 октября 2026. Это прототип; наличие кода не означает проверку на устройстве.

## Проверено локально

Android: `:shared:jvmTest`, `:androidApp:testDebugUnitTest`, `:androidApp:lintDebug`,
`:androidApp:assembleDebug`. Первая полная проверка редактора/календаря:
BUILD SUCCESSFUL, Lint 0 ошибок / 9 предупреждений (версии зависимостей и UseKtx).
Окончательные результаты после ревью записываются в REVIEW.md.
Тесты проверяют импорт v1/v2, ЗС/повторы/null, даты, время, backup,
сохранение личных переносов и обработку удаления события источником.

Windows-сборка потребовала ASCII-каталога для build output; исходники не перемещались.
Предупреждения окружения: версия SDK XML новее парсера AGP; native-библиотека
graphics.path упакована без stripping. Это не ошибки компиляции.

## Не проверено / отсутствует

- Реальное Android-устройство, TalkBack, большой шрифт, поворот и process death.
- iOS сборка на Windows невозможна; добавлены SwiftUI-код, XcodeGen и macOS CI.
- iOS пока не имеет Android-паритета: нет файлового backup UI, Google calendar handoff,
  изменения количества колонок и настроек компактности.
- МЭШ API/OAuth исключены из реализации по заданию. Датированные данные/кеш МЭШ
  и реальные оценки не реализованы до появления контракта API.
- ML Kit GenAI не включён из-за ранее обсуждённых условий для школьного продукта.
  Другой движок и модель пока не выбраны. NPU-ускорение не заявляется.
- Google API синхронизация требует своего OAuth-проекта; есть системный экспорт.
- Фоновые напоминания, порядок вкладок/карточек и цвета предметов не реализованы.

## Ручная приёмка

1. Создать неделю, добавить ЗС и повтор предмета, две колонки с null.
2. Скопировать вторую неделю, изменить только её и переключить вкладки.
3. Проверить импорт/экспорт v1/v2, ошибочный JSON и неизменность старого файла.
4. Создать контрольную, all-day событие и задание; изменить дату/отметку.
5. Восстановить копию; повреждённая копия не должна менять прежние данные.
6. Экспортировать событие в календарь и отменить там; приложение не должно считать
   это синхронизацией. Проверить московское время и all-day UTC границы.
7. Проверить тему, крупный шрифт, screen reader, маленький экран и перезапуск.
