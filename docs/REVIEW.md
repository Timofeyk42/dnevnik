# Ревью и проверка реализации

24 октября 2026. Ревью проведено основным агентом и отдельным агентом без изменения
им файлов. После замечаний добавлены регрессии, выполнены сборки и тесты на Pixel.

## Android: результаты

- 33 теста shared (22 расписания, 11 планировщика), 4 Android unit-теста: без ошибок.
- 2 instrumented-теста на **Pixel 10, Android 17, API 37**: без ошибок.
- Lint: 0 ошибок / 14 предупреждений; debug APK собран. Версии зависимостей закреплены; рекомендации обновления
  не скрываются suppressions.
- На Pixel проверены импорт/предпросмотр/сохранение, повтор предмета, создание события,
  Activity.recreate, ошибка JSON без замены, backup/export/restore, отклонение повреждённой
  копии, UTC-границы all-day и московское время календарного Intent.
- Вручную на Pixel создан синтетический урок, скопирована вторая неделя и проверен
  полный stop/start. SHA-256 файла расписания до/после одинаков; урок отображается после запуска.
- Тестовая сборка имеет отдельный applicationId `.debug` и подпись «Дневник (тест)»;
  исходное приложение и его данные не изменялись.
- Автоматический тест Activity.recreate не выдаётся за тест process death. Для полного
  stop/start вручную подтверждено восстановление расписания; все состояния черновиков
  и все сценарии process death не проверены.

## Проверка публикации

GitHub CI: Android и iOS прошли для коммита `990e503`. iOS workflow
собрал Kotlin XCFramework для arm64 device и обеих архитектур Simulator, затем
SwiftUI-приложение без release signing. Это подтверждает компиляцию, а не поведение
на iPhone. Прогоны: [Android](https://github.com/Timofeyk42/dnevnik/actions/runs/40126183886),
[iOS](https://github.com/Timofeyk42/dnevnik/actions/runs/40126183768).

Публикация выполнена явным allowlist. Проверены tracked paths и строковые patterns
секретов; local-data, учебные отчёты, фото, local.properties, кеши, сборки и ключи не
публиковались. История начинается с чистого стартового README. CI Actions закреплены
на SHA, Gradle wrapper distribution — на SHA-256. TODO остались только в отключённых
mesh/auth шаблонах. Это проверка выбранного набора, а не формальная гарантия отсутствия
всех возможных уязвимостей.

## Оставшиеся границы

Подключение МЭШ API/OAuth исключено по заданию. ИИ/NPU-движок не подключён.
Google API sync, фоновые напоминания, произвольный порядок вкладок и цвета предметов
пока не реализованы. Google Calendar проверен как сформированный системный Intent;
фактическая запись в календарь пользователя не выполнялась.
TalkBack, очень крупный шрифт и длительное использование ещё требуют ручной приёмки.
Статус iOS и различия платформ — в IMPLEMENTATION_STATUS.md и iosApp/README.md.
