# Участие в разработке

Обсуди изменения формата JSON и авторизации до реализации. Для фиксов добавляй регрессию на реальный сценарий; не используй реальные данные детей в fixtures.

Проверки:

```sh
./gradlew :shared:jvmTest :androidApp:testDebugUnitTest :androidApp:lintDebug :androidApp:assembleDebug
```

Не коммить `local.properties`, ключи подписи, токены, cookies, HAR, реальные оценки, ДЗ или фото. В PR укажи изменившееся поведение, ограничения и результаты проверок. Изменения авторизации требуют проверки по `SECURITY.md`.
